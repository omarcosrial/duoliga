# DuoLiga v2.5

Versão atualizada com o novo visual inspirado nas telas aprovadas.

## O que foi mantido
- Cadastro de participantes.
- Senha individual de 4 dígitos.
- Foto de perfil.
- Exclusão de perfil.
- Dados compartilhados com Netlify Blobs.
- Check-in com minutos, XP e comprovante.
- Temporada de 8 semanas.
- Conversação presencial de 5 minutos.
- Missões, conquistas, ranking, prendas, cofrinho e cutucadas.

## Novo visual
- Início com pódio, prêmio acumulado, meta, missão e movimentação do dia.
- Check-in redesenhado no estilo das telas de referência.
- Desafios com três modos: Meta, Conversação e Missão.
- Modo Conversação com cronômetro de 5 minutos, temas, participantes e votação.
- Missão da Semana com conquistas.
- Mais com Devedores, Cutucar, Histórico, Tela do Campeão e configurações.
- Barra inferior elevada no celular para reduzir a sobreposição da marca flutuante do Netlify.

## Atualização no GitHub
1. Extraia o ZIP.
2. No repositório `duoliga`, clique em **Add file > Upload files**.
3. Envie todo o conteúdo desta pasta, substituindo os arquivos existentes.
4. Clique em **Commit changes**.
5. O Netlify deverá iniciar o deploy automaticamente.

A configuração do banco e das Functions continua a mesma da versão anterior.
